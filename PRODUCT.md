# Formgefühl

## Platform
Web experience, desktop and mobile, complete German and English versions. Top-right DE/EN selection, native browser back/forward navigation, and a persistent Salon Format / All projects link. Short, friendly language.

## Purpose
A compact, immersive learning experience by Salon Format, inspired by the Wiener Werkstätte. Visitors create a motif, explore repetition and scale, enter a patterned space, and learn about the Gesamtkunstwerk. The work should be credible to present to the MAK without implying a commission or partnership.

## Confirmed direction
User approved the pattern-to-room experience and supplied https://infinite.salonformat.com as their own reference. Preserve Salon Format authorship, Della Respira and its approachable, artistic character. Use colors relating to the Wiener Werkstätte and MAK. Learning must arise from doing, with short explanations.

## Delivery
Local working experience and a new GitHub repository in salonformat, private by default. No changes to existing Salon Format sites. User has authorized repository creation and source backup.

## Implementation choice
Vite, vanilla JavaScript and Three.js. No backend, account, tracking, or paid service. Original procedural geometric compositions; never present them as historical reproductions.
